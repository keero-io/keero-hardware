# Tracks Module

The tracks module represents the mobility direction of the Keero Bot platform.

It is intended for:

- movement experiments
- embodied AI demos
- robotic interaction concepts

## Attribution

This mobility direction is inspired by the ESP-SparkBot concept.

Because of that, the public Keero repository keeps the mechanical references visible and credits that lineage openly instead of presenting the whole module as a fully isolated original concept.

## Keero Adaptation

The active Keero work around this module focuses on:

- module integration into the broader Keero platform
- Keero-authored open-source firmware
- an updated controller direction using `ESP32-C3-WROOM-M2`
- a workflow that runs cleanly with Arduino and PlatformIO

## Public Assets

The `3D` folder contains the public mechanical reference files currently shared with the project so they can be previewed and downloaded from the documentation site as well.
